# 逻辑回归（Logistic Regression）详解

## 一、基本概念

逻辑回归虽然名字带"回归"，但实际上是一个**分类算法**，常用于二分类问题。

### 核心思想

```
线性回归：  ŷ = w·x + b          → 输出范围 (-∞, +∞)
逻辑回归：  ŷ = σ(w·x + b)       → 输出范围 (0, 1)
```

逻辑回归 = 线性回归 + **Sigmoid 激活函数**，将输出映射为概率。

### Sigmoid 函数

```
σ(z) = 1 / (1 + e^(-z))
```

```
σ(z)
  1 |                   ___________
    |                 /
    |               /
 0.5|-------------/-----------  ← 阈值（通常0.5）
    |           /
    |         /
  0 |________/
    +--------------------------------→ z
```

| 特性 | 说明 |
|------|------|
| 输出范围 | (0, 1)，可解释为概率 |
| z = 0 时 | σ(0) = 0.5 |
| z → +∞ | σ(z) → 1 |
| z → -∞ | σ(z) → 0 |
| 导数 | σ'(z) = σ(z) × (1 - σ(z)) |

### 预测规则

```
P(y=1|x) = σ(w·x + b)

若 P(y=1|x) ≥ 0.5  → 预测为正类（1）
若 P(y=1|x) < 0.5  → 预测为负类（0）
```

## 二、极大似然估计（MLE）

### 什么是极大似然？

**核心思想**：找到一组参数，使得观测到当前数据的概率最大。

> 比喻：你看到10次抛硬币有7次正面，你会猜测"这枚硬币正面概率大概是0.7"——这就是极大似然。

### 逻辑回归的似然函数

对于单个样本：

```
P(y|x) = ŷ^y × (1-ŷ)^(1-y)
```

- 当 y=1 时：P = ŷ（预测为正类的概率）
- 当 y=0 时：P = 1-ŷ（预测为负类的概率）

对于所有 n 个样本（似然函数）：

```
L(w,b) = ∏ᵢ ŷᵢ^yᵢ × (1-ŷᵢ)^(1-yᵢ)
```

### 取对数（对数似然）

连乘不好计算，取 log 转为连加：

```
log L = Σᵢ [yᵢ × log(ŷᵢ) + (1-yᵢ) × log(1-ŷᵢ)]
```

**极大似然 = 最大化 log L**

---

## 三、损失函数（Loss Function）

### 交叉熵损失（Cross-Entropy Loss）

由于优化算法通常是最小化损失，所以把对数似然取负：

```
Loss = -(1/n) × Σᵢ [yᵢ × log(ŷᵢ) + (1-yᵢ) × log(1-ŷᵢ)]
```

这就是**二元交叉熵损失**（Binary Cross-Entropy）。

### 直观理解

| 真实标签 y | 预测概率 ŷ | Loss | 含义 |
|-----------|-----------|------|------|
| 1 | 0.99 | -log(0.99) ≈ 0.01 | 预测很准，损失很小 |
| 1 | 0.50 | -log(0.50) ≈ 0.69 | 预测不确定，损失中等 |
| 1 | 0.01 | -log(0.01) ≈ 4.60 | 预测很错，损失很大 |
| 0 | 0.01 | -log(0.99) ≈ 0.01 | 预测很准，损失很小 |
| 0 | 0.99 | -log(0.01) ≈ 4.60 | 预测很错，损失很大 |

```
Loss
 ↑
 |  \
 |   \          ← y=1 时，ŷ 越接近1损失越小
 |    \
 |     \___
 +-----------→ ŷ
```

### 梯度下降更新

```
∂Loss/∂w = (1/n) × Xᵀ·(ŷ - y)
∂Loss/∂b = (1/n) × Σ(ŷ - y)

w = w - α × ∂Loss/∂w
b = b - α × ∂Loss/∂b
```

> 注意：形式上和线性回归的梯度一样！但 ŷ 的计算不同（多了 Sigmoid）。

## 四、逻辑回归与线性回归的关系

| 对比项 | 线性回归 | 逻辑回归 |
|--------|---------|---------|
| **任务** | 回归（预测连续值） | 分类（预测类别） |
| **输出** | (-∞, +∞) | (0, 1) 概率 |
| **激活函数** | 无 | Sigmoid |
| **损失函数** | MSE | 交叉熵 |
| **假设** | 线性关系 | 线性决策边界 |
| **基础** | — | 线性回归 + Sigmoid |

### 关系图

```
线性回归                        逻辑回归
┌──────────────┐              ┌──────────────┐
│  z = w·x + b  │  ──Sigmoid──→  │ ŷ = σ(w·x+b) │
│  ŷ = z        │              │  ŷ ∈ (0, 1)   │
│  Loss = MSE   │              │  Loss = CE     │
└──────────────┘              └──────────────┘
```

**逻辑回归 = 线性回归套了一层 Sigmoid + 换了损失函数**

## 五、评估指标

### 5.1 混淆矩阵（Confusion Matrix）

```
                    预测
                 正类(1)    负类(0)
实际  正类(1) │  TP(真正)  │  FN(假负)  │
      负类(0) │  FP(假正)  │  TN(真负)  │
```

| 缩写 | 名称 | 含义 |
|------|------|------|
| **TP** | True Positive | 真正例：实际是正，预测也是正（猜对了） |
| **TN** | True Negative | 真负例：实际是负，预测也是负（猜对了） |
| **FP** | False Positive | 假正例：实际是负，预测是正（误报） |
| **FN** | False Negative | 假负例：实际是正，预测是负（漏报） |

> 记忆技巧：第一个字母 T/F 表示预测是否正确，第二个字母 P/N 表示预测的类别。

### 5.2 精确率（Precision）

```
Precision = TP / (TP + FP)
```

**含义：预测为正类的样本中，真正是正类的比例。**

> 比喻：你发了100封垃圾邮件告警，其中90封真的是垃圾邮件 → Precision = 90%

**关注点：减少误报（FP）**

- 高精确率 = 预测为正的都很准 = 误报少
- 场景：垃圾邮件过滤（宁可漏掉，也不能把正常邮件当垃圾）

### 5.3 召回率（Recall）

```
Recall = TP / (TP + FN)
```

**含义：所有真正是正类的样本中，被正确预测出来的比例。**

> 比喻：100个真正的病人，模型找出了85个 → Recall = 85%

**关注点：减少漏报（FN）**

- 高召回率 = 正类样本很少被漏掉 = 漏报少
- 场景：癌症筛查（宁可误报，也不能漏掉真正的患者）

### 5.4 精确率 vs 召回率的权衡

```
阈值 ↑  →  精确率 ↑  召回率 ↓  （严格，只报最有把握的）
阈值 ↓  →  精确率 ↓  召回率 ↑  （宽松，尽量不漏报）
```

| 场景 | 优先 | 原因 |
|------|------|------|
| 癌症筛查 | 召回率 | 漏诊代价极大 |
| 垃圾邮件 | 精确率 | 误杀正常邮件代价大 |
| 推荐系统 | 精确率 | 推荐不准影响用户体验 |

### 5.5 F1 分数

```
F1 = 2 × (Precision × Recall) / (Precision + Recall)
```

**精确率和召回率的调和平均数**，综合评价模型性能。

- F1 = 1：完美（精确率和召回率都是100%）
- F1 = 0：最差
- F1 对不平衡数据特别有用

### 5.6 ROC 曲线

**ROC（Receiver Operating Characteristic）曲线**：

- 横轴：假正率 FPR = FP / (FP + TN)
- 纵轴：真正率 TPR = Recall = TP / (TP + FN)

```
TPR(Recall)
  1 |    ___________
    |   /
    |  /    ← 好模型，曲线贴近左上角
    | /
    |/
  0 +------------→ FPR
    0            1
```

**绘制方法**：遍历所有可能的阈值，每个阈值算一个 (FPR, TPR) 点，连成曲线。

| 曲线位置 | 含义 |
|---------|------|
| 贴近左上角 | 模型越好（TPR高，FPR低） |
| 对角线 | 随机猜测（没有区分能力） |
| 低于对角线 | 比随机还差（可以翻转预测） |

### 5.7 AUC（Area Under Curve）

```
AUC = ROC 曲线下的面积
```

| AUC 值 | 模型性能 |
|--------|---------|
| 1.0 | 完美分类 |
| 0.9 - 1.0 | 优秀 |
| 0.7 - 0.9 | 良好 |
| 0.5 - 0.7 | 一般 |
| 0.5 | 等同随机猜测 |
| < 0.5 | 比随机差 |

**AUC 的概率解释**：随机取一个正样本和一个负样本，模型给正样本的预测概率高于负样本的概率。

## 六、总结对比表

### 评估指标汇总

| 指标 | 公式 | 关注点 | 适用场景 |
|------|------|--------|---------|
| **精确率** | TP/(TP+FP) | 减少误报 | 垃圾邮件、推荐 |
| **召回率** | TP/(TP+FN) | 减少漏报 | 疾病筛查、风控 |
| **F1** | 2×P×R/(P+R) | P和R的平衡 | 不平衡数据 |
| **AUC** | ROC曲线下面积 | 整体排序能力 | 通用评估 |

### 混淆矩阵完整图

```
                 预测为正        预测为负
实际为正     TP(真正例)      FN(假负例/漏报)
实际为负     FP(假正例/误报)  TN(真负例)

准确率 = (TP + TN) / (TP + TN + FP + FN)
精确率 = TP / (TP + FP)
召回率 = TP / (TP + FN)
F1    = 2 × 精确率 × 召回率 / (精确率 + 召回率)
```
